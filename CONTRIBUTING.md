# Contributing

## ⭐ The most valuable contribution: a real interview question

If you interviewed for an Applied AI, FDE, AI Deployment, ML or AI-agents role, please share what you were asked. It keeps this handbook current and helps the next person.

**Open an issue** with:

- **Role & company**, e.g. "Forward Deployed Engineer, Anthropic"
- **Round**: recruiter screen, coding (AI allowed or not?), applied-AI deep dive, system design, take-home, discovery role-play or behavioral
- **Date**: month and year. Freshness matters because these loops change every quarter.
- **The question(s)**, word for word if you can
- *(Optional)* how you answered, or what they seemed to be looking for

Don't share anything covered by an NDA or proprietary take-home content. Describe the kinds of questions asked.

## Corrections & updates

The field moves every quarter, so corrections are very welcome. For a factual claim, link a **dated source** and say whether it's **official** (from the company or spec) or **reported** (a candidate account). See [SOURCES.md](./SOURCES.md) for the format.

## How the files are built

`topics/*.md`, `flashcards.md` and `interview-questions.md` are generated from the same source as the [interactive trainer](https://deployprep.vercel.app), so the two stay in sync. PRs to these files are welcome: accepted changes are ported to the source so they survive the next regeneration. `README.md`, `CHANGELOG.md`, `SOURCES.md` and this file are written by hand.

## Style

- **Answer first.** Put the answer in the first sentence, then explain.
- Write what a **strong candidate actually says**, not textbook filler.
- **Date anything that will age**, such as model names, prices, API features and company loops.
- Concise beats comprehensive.

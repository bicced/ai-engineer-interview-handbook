# Contributing

## ⭐ The most valuable contribution: a real interview question

If you interviewed for an Applied AI / FDE / ML / AI-agents role, share what you were asked. It keeps this handbook current and helps the next person.

**Open an issue** (or PR to the relevant `topics/*.md`) with:

- **Role & company** (e.g., "Forward Deployed Engineer, Anthropic")
- **Round** (recruiter screen / coding / applied-AI deep dive / system design / behavioral)
- **Date** (month + year — freshness matters; these loops change fast)
- **The question(s)** — verbatim if you can
- *(Optional)* how you answered / what they were looking for

No NDAs-breaking specifics or proprietary take-home content, please — just the kinds of questions asked.

## Other contributions

- **Corrections & updates** — the field moves every quarter; fixes welcome.
- **New questions & answers** for the bank.
- **New topics** — open an issue to discuss scope first.

## Style

- Keep it **accurate and current** (2026). Cite sources for non-obvious claims.
- Answers should say **what a strong candidate actually says**, not textbook filler.
- Concise > comprehensive. Lead with the answer.
